# Projet "Bataille navale"

## À propos
Une version simplifiée de la bataille navale en mode texte avec un joueur, une grille de 8 lignes par 10 colonnes et 4 types de bateaux placés aléatoirement sans chevauchement.

## Utilisation
Installez les dépendances avec `pip install -r requirements.txt`, puis exécutez `main.py`.
